The service applies a request size limit, extracted-text and PDF-page limits, and an in-memory rate limit per client. These controls prevent abuse and protect the vector database from oversized uploads. Operators can require an X-API-Key for document ingestion to reduce corpus-poisoning risk. Secrets should be stored in environment variables and never checked into source control. Use rotating API keys for downstream providers to reduce exposure. Logs intentionally avoid capturing raw document contents. Network access should be scoped to internal subnets when deploying in production.
